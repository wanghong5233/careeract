### 历史原型复现

在仓库根目录运行，不需要 Docker、模型 Key 或业务服务：

```powershell
python -m http.server 3210 --bind 127.0.0.1 --directory docs/topics/workspace/prototype
```

浏览器打开 `http://127.0.0.1:3210/`。仅用于明确需要的历史回溯，不用于评审当前 Codex 骨架。
右上角“预览状态”可查看空项目、保存失败、版本冲突和提交结果未知。
所有人物、学校、企业与经历为虚构示例；操作只修改页面内存，刷新重置。
未读取真实环境配置，未调用模型、数据库或外部招聘站。本地搜索、申请筛选/汇总、
材料草稿/历史、托管配置等已能操作；文件解析、真实搜索/模型/语音/提醒/导出仍为界面预留。

原型源文件与虚构截图逐文件放行 Git；其他设计研究、私人资料及未审查图片继续忽略。
版本历史由 Git 保存，不按对话堆放副本。实际验收结果在本节补充，不写成业务集成通过。

- 可见浏览器检查 22 个视图均可渲染；检查时未捕获页面 JS 错误。
- 实际操作通过：申请按公司查询/汇总、全局按编号查找、状态追加和历史保留、关联材料进入准备。
- 实际操作通过：材料正文编辑生成新草稿、历史恢复；委托与上下文记录后可打开相关工作。
- 实际操作通过：托管只读默认、授权摘要、开启/暂停/恢复/撤销、撤销后拒绝模拟运行。
- 实际操作通过：提交结果未知时确认按钮禁用，停止后续动作保留未知结果；模拟回执关联申请时间线。
- 390×844 浏览器模拟检查申请、沟通、准备、资料、托管、决策与成长页，没有整页或主区横向溢出；
  窄屏导航可切换，结束恢复默认窗口。不是手机真机验证，也未验收全部键盘/辅助技术路径。
- 两份 JS 语法检查、差异格式、4 份修改文档的 41 处本地链接与私人资料忽略边界通过；
  原型目录 Gitleaks 扫描无发现。未运行正式应用全栈测试或任何真实业务集成。

未接入能力保留入口和边界，不填入虚构职业记录、不模拟业务完成。职业背景默认阅读，

未写入私人职业档案；材料提议、执行、导出、提醒、实时语音和托管仍未接入。
