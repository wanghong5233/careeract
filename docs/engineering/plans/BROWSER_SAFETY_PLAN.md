# 浏览器接管与单写入边界

范围：单浏览器并发的本地基础设施集成，先用虚构表单验证。
不执行真实招聘提交，不把内部 CDP 或 Viewer URL 暴露为产品入口。

## 当前阶段

已实现进程内规则、PostgreSQL 租约存储、Ed25519 短时命令验证及内部控制路由。
两进程竞争、进程退出后的所有权保持、迁移和 HTTP/数据库联合验收已通过。
API 签名/HTTP 适配器已连接独立 Browser 进程，支持签名注册、撤销及租约命令；
API 接收用户请求后的授权记录校验与签发用例尚未接入。
内部入口默认关闭，需要显式配置数据库和签名公钥；尚未接入产品授权用例或前端，
Steel 仅完成下述独立执行器测试，未接入生产控制链。
数据库互斥不能替代 CDP 连接隔离，不能宣称生产浏览器安全隔离已实现。

执行器生命周期模块已验证：停止后拒绝新动作、等待在途操作、断连确认后释放；
失败/取消/超时保持结果未知。真实 Steel + PostgreSQL 验收确认旧 Playwright 连接
断开、旧页面对象无法写入、页面内容保留。尚未验证同源 Viewer 的授权交接。
此前一次 Windows Computer Use 验收因工具无法识别浏览器 URL 未执行；这是当次工具限制，
不是已证明的产品缺陷。可见验收单独保留，不阻塞后台服务检查。

## 后续顺序与验收

以下是开放浏览器功能的前置验收，不阻塞职业档案等不使用浏览器的功能开发。
项目当前任务顺序以 [STATUS](../STATUS.md) 为准，未通过时保持控制入口关闭。

1. 持久会话归属和服务间授权：API 根据用户 Session、任务与授权记录生成短时凭证，
   Browser 验证 audience、有效期及会话范围；不能信任请求正文里的 user_id。
   在已有 PostgreSQL 上实现跨进程原子获取/续租/交接，新增 Schema 走 Alembic。
   验收跨用户拒绝、错误/过期凭证拒绝、两个进程竞争及服务重启后的保守恢复。
   已完成 Browser 侧存储/验证与 API 内部签名/注册/撤销适配器；业务授权记录及
   对外用例仍待接入，不将内部签名器直接作为面向客户端的令牌签发接口。
2. 执行器连接生命周期：停止新动作，等待在途操作停止或升级为结果未知，
   关闭旧连接并确认旧执行器不能重连，之后才交接；不能只靠 TTL 或检查后发命令。
   验收旧 token、断线、超时、撤销及接管竞争，结果未知的外部写入不自动重试。
3. 同源 Viewer 代理：复用 Better Auth/BFF 身份链，WebSocket 升级时验证 Origin、
   Session 和会话所有权；撤销后关闭已有通道。先确认当前 Caddy/Next.js 部署中
   WebSocket 转发的可实现路径，再接入页面，不默认普通 Route Handler 可代理升级。
4. 可见 Computer Use 验收：虚构页面里 Agent → 人工 → Agent 互斥、跨用户拒绝、
   撤销断连、刷新与退出；保留 Viewer 窄窗口、快捷键和中文输入法的独立验收项。

## 必须保留的约束

- 租约过期只让写入失效，不证明旧浏览器动作已停，也不自动授予下一个执行器。
- 同一用户的两个执行器也要互斥；不能只比较 user_id 或执行器类型。
- 数据库记录本身不能阻止旧 CDP 连接写入，必须配合执行器生命周期和连接隔离。
- 进程重启不能把仍存活的 Steel 会话当作空闲；无法确认所有权时关闭或隔离后恢复。
- Viewer 接入属于安全边界，只有以上验收通过才能声称人工接管已实现。
