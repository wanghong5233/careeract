# CareerAct 当前状态

更新：2026-09-29。只维护当前结论、下一步和可复查证据，不逐轮追加开发日志。

## 阶段结论

已完成关键基建收尾和第一条职业业务功能：用户可在工作台维护、确认并保存职业档案，
刷新后恢复，跨用户读写隔离，过期版本不能覆盖新数据。Agent 已移到辅助面板。
这是一条可运行的本地业务路径，尚不是完整求职产品；全部基建、权限与公网部署未闭环。

产品围绕职业项目、档案、材料、岗位、申请、任务和结果组织。首要目标是自用、可复现、
可展示的工程代表作，再通过少量真实试用改善产品。采用渐进开发，不承诺短假期内公开
商业化；Star 与用户规模不是首次发布门槛。本地通过后再讨论短期云端验证，不预购季度
服务器，不默认购买或部署。模拟面试、收费、规模化推广、客户端扩展暂不展开。

## 权限专项的完成边界

- 已完成模型网关最小权限：API 必填 `LITELLM_API_KEY`，无 master 回退；迁移只需数据库
  配置。部署仅给 LiteLLM 与一次性初始化进程管理 Key，供应商 Key 只给 LiteLLM。
- 运维脚本支持准备、注册、检查、轮换和停用；重复初始化不改已有策略，blocked 记录不
  自动启用。本机 `.env.litellm` 已忽略，原供应商 Key 未修改，真实值不输出。
- 原型服务总策略为两模型别名、Chat Completions/模型列表路由、5 美元预算、`30d` 周期、
  30 RPM、60,000 TPM、单在途请求。超限拒绝，无产品排队；异步释放并发计数可能短暂
  返回 429。网关估算不等于供应商账单或绝对费用上限，试用前仍需复核。
- 档案 GET/PUT 已验证当前用户归属、客户端 user_id 拒绝和跨用户版本写入拒绝；全产品权限
  尚未完成，材料下载、Agent 会话历史、业务任务、浏览器接管须随功能验证归属与撤销。
  浏览器服务签名证明调用来源，不代替真实用户授权。
- 产品管理员后台暂不实现；云厂商控制台管理云资源，不能代替业务权限。当前账号按普通
  产品用户使用。具体边界和操作见[开发指南](DEVELOPMENT.md#身份与权限边界)。

## 已交付档案与下一项

用户可手动维护教育、经历、项目/成果及来源说明、技能、目标和约束；点击“保存并确认”
后持久化，修改会清除本次确认勾选。保存失败保留输入；冲突或结果未知时停止重复保存，
由用户复制需保留的内容并明确选择重新读取服务器版本。不自动重放写入。

当前长表单验证了持久化与用户隔离，但没有落实材料导入、文档编辑、Agent 修改与 Diff。
教育/经历共用的通用条目及自由文本不足以完整表达真实网申字段；当前 UUID 只防并发覆盖，
不是可回看的历史版本。不能把这一版页面当成最终产品交互。

下一项调整为[档案与材料交互原型](../product/WORKSPACE_INTERACTION.md)：

1. 用虚构样本验证文档式阅读、局部编辑、原文入口、Agent 上下文和 Diff 接受/拒绝，
   先在可见页面验证工作方式与窄屏布局。模拟提议明确标识，不冒充模型或持久化已接入。
2. 随后围绕一份材料实施导入/粘贴、来源保留、草稿、修改提议、确认版本和只读 Agent
   上下文的最小真实路径；每次选择一个可验收目标，不一次搭建完整文档平台。
3. Agent 身份沿 Session/JWT 链传递，按服务端当前用户读取；校验空档案、更新后的版本、
   用户隔离和事实/建议区分。内容不能覆盖系统规则，也不能成为外部操作授权。
4. 原有数据与隔离规则保留，模型调整走迁移；本轮只有交互规格收口，尚未改造前端或导入真实资料。

原型遵循[产品设计原则](../product/DESIGN_PRINCIPLES.md)，官方来源与本项目取舍已分开记录。
机会发现区分单次 Agent 检索、定时重复检索和指定来源监测。已核对本仓 Agno 3.0.6 的
搜索、网页读取、MCP 和 Workflow 实现，以及外部组件的官方文档/源码；推荐优先复用现有
Agno 装配工具，仅实现求职领域筛选与核验，Temporal 负责定时与持久任务，不新增通用运行栈。
这是选型建议，尚未接入或实测：搜索供应商、中文招聘质量、国内云访问、耗时与费用仍待
验证；研究框架开源不等于搜索服务免费或可自托管。详细依据仅在所有者本地已有的
docs/archive/TECHNICAL_SELECTION.md 第 12 节维护，不把候选写成 PRD/架构的既定能力。
上一轮未经验证的机会事件、采集与提醒详细方案不再作为既定设计；
当前档案/材料原型的交付顺序不变。

页面验收优先可见浏览器，区分实际操作与后台 HTTP/自动化检查。布局细节经原型验证，
不把文档中目标行为写成已经交付。之后接岗位与材料锁定，再按
[浏览器专项计划](plans/BROWSER_SAFETY_PLAN.md)完成隔离和接管，形成可核验的申请路径。
