通用 Agent 工作面与文本 Runtime 已形成可交接基线。本轮完成最后的 UI、开发环境和入口/归档收尾，
同步文档并建立 Git 提交基线，推送按用户授权执行。前端收尾已结束，下一阶段切入职业业务：优先推进
BOSS 直聘的合适岗位筛选与招聘方主动沟通最小闭环，复用已有 Runtime、职业上下文和浏览器执行边界。

招聘沟通已进入业务增量开发：BOSS 连接请求和有限登录任务可按登录用户持久化、刷新恢复和版本条件撤销，
已通过真实认证/BFF/PostgreSQL 链路与合成桌面可见检查。产品卡片现在提供明确的安全登录、等待、打开
同源安全浏览器和停止入口；未配置 Browser Service 时仍安全关闭，不把请求记录称为已登录；
内部 Steel 创建/核对/释放适配已通过合成会话集成，并已绑定产品登录请求；
固定 Steel 实例的两个顺序会话 canary 已确认新会话不继承合成网页存储；
同源 Viewer 的 HTML 地址重写、会话绑定和 Origin 校验组件已通过专项测试；
Browser Service 内部 Viewer HTML 路由和受保护的 API 短时票据签发已通过合成测试；票据只有在
已注册且未撤销的 `browser.sessions` 记录存在时才可签发。内部按用户/站点加密的 Cookie/localStorage
快照已通过合成保存、重建恢复和撤销验证；真实登录态、Profile 目录隔离/清理尚未验证，
内部登录任务/有限授权/尝试已持久化，并贯通签名 Browser Service 归属注册与撤销；Viewer 票据校验
这些对象和有效期限。内部受签名保护的 Steel 创建/释放已绑定真实执行对象并通过隔离集成；
只有创建回读确认后才可签发 Viewer 票据。产品 HTTP、同源 Viewer HTML 代理和本地 Web rewrite 已装配；
真实 Steel WebSocket、用户人工登录、Profile 持久化与真实 BOSS 状态回写仍待可见环境验收。
